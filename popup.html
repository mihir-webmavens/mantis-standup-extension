        MantisAI

        Chat about Mantis tickets with the Claude CLI on this computer.

        Checking…
        1. Allow the extension to talk to the local helper.
        2. Download the installer and run it in a terminal:
          bash ~/Downloads/mantis-ai-install.sh
        3. Check the connection.

        Needs Node.js 18+ and Claude Code, logged in (claude), with the Mantis connection webmavens-projects signed in (/mcp) for lookups. Changes in Mantis always ask for your approval. Linux and macOS.
